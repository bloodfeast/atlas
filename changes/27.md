- **Reads in a git worktree now get the code index's help.** A file in a linked worktree of an indexed
  repository, such as Claude Code's `.claude/worktrees/` or a worktree beside the checkout, used to get no
  outline or item annotations. It is now scanned from its own bytes and mapped to the root it belongs to,
  with that root's walk rules, `exclude` globs and size limit. Nothing is written to the index.
