- **atlas tells you when it has stopped.** If every atlas server of a Claude Code session has exited, or a `/clear` after a plugin update dropped it, the next prompt says so once: run `/mcp`, or restart with `claude --continue`. Before, every hook failed silently.
- **Hooks are command hooks that hand their event to the session's own server.** A subagent's brief, the caps and what was already said stay in one process, as with the `mcp_tool` hooks. On Windows, or when the server cannot be reached, the hook runs in its own process. On Linux, `atlas --hook` run through a shell below Claude Code, such as from the Bash tool, does nothing.
