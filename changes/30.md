- **C++ in the code index.** C++ files get definitions, kinds and item ranges from atlas's own scanner, with
  nothing installed. With scip-clang on `PATH` and a `compile_commands.json`, `symbol` gives references and
  callers too. scip-clang runs the compilers that file names, so it runs only where you allow it:
  `code.roots[].cpp.trust` is off by default, `"ask"` runs it once you approve the file with
  `atlas trust cpp ROOT` (asked once at session start, again after it changes), and `"always"` runs it
  anyway. A compiler inside the repository, or an argument outside what indexing needs, is always refused.
- **atlas's questions come first.** The project, orchestrated-mode and C++ questions now open the first
  reply, before the task, rather than after a long first turn.
