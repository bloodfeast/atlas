# `COUNT path:U+XXXX reason` per line, which lets COUNT of that character

# character, never by line numbers, so an edit above a case cannot make its
# entry stale. The file must hold exactly COUNT of the character: one more
# (a new hidden character in an allowed file) or one fewer fails, and the
# gate names the count to set; an entry that matches nothing is an error.
